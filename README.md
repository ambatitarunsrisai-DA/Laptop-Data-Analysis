# Laptop Data Analysis using Python

I recently completed a Laptop Data Analysis Project where I explored and visualized insights from a dataset containing various laptop specifications and prices.

# Project Overview:
The goal was to analyze how laptop features such as brand, RAM, processor, display type, and price relate to one another — and to uncover which factors influence pricing trends in the market.

# Key Steps & Insights:

Python → (obviously, base language)
Pandas → used for loading, cleaning, describing, and analyzing data (pd.read_csv, df.describe, drop_duplicates, etc.)
NumPy → indirectly used (since you used .median() and some numeric operations rely on NumPy).
Matplotlib → used for creating visualizations (plt.figure, plt.show()).
Seaborn → used for plots like bar charts, countplots, and heatmaps.
Google Colab → used as your execution environment (files.upload() confirms that).
